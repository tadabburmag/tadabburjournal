ضوابط الاستخدام

- لا ينسخ أي قالب مباشرة إلى Production.
- يبدأ العمل في Branch مستقل.
- يختبر على Staging.
- index.tpl وindex.json إلزاميان.
- index.css وindex.js اختياريان.
- العربية تستخدم ar وrtl.
- أي CSS أو JavaScript خام داخل index.tpl يلف داخل literal و /literal.
- يمنع وضع أسرار أو مفاتيح داخل الملفات.
- يعتمد النشر وفق مسار OJT بعد المراجعة والموافقة.
